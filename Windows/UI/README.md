# PocketOS v3.4.0 Tab UI Polish

Usage:

After creating the Settings TabControl:

var tabs = new TabControl
{
    Dock = DockStyle.Fill
};

TabControlStyler.Apply(tabs);

Current tabs:
- Pokemon Partner
- Wi-Fi
- Shiny Hunt
- Settings
- Updates

Purpose:
Replace default Windows WinForms tab appearance with PocketOS style.
